# Landpot

**landpot.fun** — браузерная стратегия за территории в мире блоков, нод и пулов.

## Банк раунда

Игроки вносят токены в общий банк. В конце раунда банк делится пропорционально числу блоков под контролем каждого игрока. Нейтральные блоки исключены из расчёта до захвата.

Захват блока у соперника сразу меняет прогноз выплат для обоих игроков. Токены остаются в банке до конца раунда. Например, при банке в 100 токенов захват 10 блоков может изменить прогноз с **50 / 30 / 20** на **60 / 20 / 20**.

## Карта

- **Блоки** определяют долю банка.
- **Ноды** связывают участки карты.
- **Пулы** ускоряют подкрепление.

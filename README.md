# Landpot

**landpot.fun** — браузерная стратегия за территории в мире блоков, нод и пулов. В конце раунда общий банк делится пропорционально контролируемой территории. Захват меняет прогноз выплаты сразу. Ноды усиливают соседние гарнизоны, пулы ускоряют производство подкреплений.

## Запуск

Требуется Node.js 24+.

```sh
npm ci
npm start
```

Откройте `http://127.0.0.1:3000`. В демо выберите свой блок, затем соседний. Ползунок задаёт долю отправляемого гарнизона. Онлайн-очередь бесплатного режима принимает от двух игроков. Очередь с тестовым банком стартует от восьми. Для проверки нескольких участников используйте независимые профили браузера.

Тестовый банк использует внутренний реестр и не имеет денежной стоимости. Баланс и выплаты хранятся в SQLite. По умолчанию файл базы находится в `data/landpot.db`. Для HTTPS за обратным прокси задайте `LANDPOT_SECURE_COOKIE=1`. Полный список параметров находится в `config.mjs`.

```sh
npm run check
npm run build:demo
npm run compile:contract
```

Содержимое `dist/` после сборки демо можно раздавать как статический сайт. Онлайн-очередям нужен Node-сервер. Эскроу компилируется отдельно и не подключён к внутреннему реестру.

## Ручная проверка

Задайте `LANDPOT_ADMIN_TOKEN` для доступа с заголовком `Authorization: Bearer …`:

- `GET /api/admin/review` — матчи на проверке.
- `GET /api/admin/replay/<id>` — журнал тестового матча.
- `POST /api/admin/review` — JSON с идентификатором `id` и решением `action` (`approve` или `refund`).

Для воспроизведения скачанного журнала выполните `node scripts/replay.mjs match.json`.

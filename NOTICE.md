## Modifications (prominent notice, AGPL-3.0 section 5(a))

Started from upstream commit `8f1a0ad` (November 2026).

- `proprietary/` removed; `brand/` holds Landpot's replacements at the same
  relative paths, generated by `scripts/landpot/make-brand-assets.mjs`;
  `getProprietaryDir()` now points at `brand/`. The proprietary display font is
  no longer loaded.
- Ads, ad-block recovery (AdShield, Admiral), Playwire RAMP, Google Tag / gtag,
  Cloudflare Web Analytics and the CrazyGames SDK removed from `index.html`;
  `window.adsEnabled` is always false.
- The game's name in UI strings reads "Landpot" (`src/client/LangSelector.ts`);
  page title, meta tags and structured data renamed.
- Footer: OpenFront community links, Steam promo and OpenFront Inc.'s legal
  pages removed; copyright notice kept; "based on OpenFrontIO", licence and
  source links added.
